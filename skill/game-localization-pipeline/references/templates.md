# 산출물 틀

## §1 분석 보고서

```
# <게임 이름> (<기종>, <판본·ID>) 한글화 분석

## 판정: 가능 / 조건부 가능 / 불투명 / 불가능
한 줄 이유.

## 분량
| 항목 | 값 |
|---|---|
| 텍스트 파일 | 형식, 개수 |
| 메시지 수 / 순수 글자 수 | |
| 고유 글자 수(한자·가나) | |
| 글자가 박힌 그림 | 개수(있는 분야만: UI·배경·타일·이펙트·3D·영상 등) |

## 재삽입
| 항목 | 결과 |
|---|---|
| 텍스트 무변경 왕복 | 바이트 일치 n/n |
| 아카이브 무변경 재패킹 | 바이트 일치 여부 |
| 폰트 | 형식, 칸 수, 한글 2,350자 수용 여부, 고정폭 여부 |
| 그래픽 | 형식·압축·스위즐, 인코더 유무 |
| 체크섬·서명·크기 제한 | |

## 위험 요소
- …

## 분야 목록·실행 환경
| 분야 | 있음/없음 | 파일 위치·형식 | 비고 |
|---|---|---|---|
| (게임에 있는 분야만 채우고, 후보 중 없는 것은 「없음」) | | | |

- 배포 대상 환경: 실기(기종·방식) / 에뮬레이터(이름)
- 원본을 넣는 방식: 롬 교체 / 파일 치환 플러그인 / 재빌드 등

## 다음 단계
- 한글 출력 시험 대상 문구: …
```

## §3 그래픽 규칙표 (작업 전에 승인받는다)

```
| 항목 | 규칙 |
|---|---|
| 규격 | 원본과 같은 크기·형식·밉맵·투명도 |
| 지우기 | 글자 픽셀만(네모 금지), 보호할 요소: … |
| 바탕 복원 | 방법: … |
| 글꼴 느낌 | 굵기·테두리·그림자·그라데이션을 원본에 맞춤 |
| 번역문이 길 때 | 1) 글자 크기 줄이기(최소 …px) 2) 가로 압축(최대 …%) 3) 줄바꿈 허용 여부 |
| 번역문이 짧을 때 | 정렬 기준(가운데·왼쪽), 크기 유지 |
| 기울어진 글줄 | 일자로 쓰고 줄 전체를 원본 각도로 회전 |
| 영문 표기 | 원문이 영어인 디자인 글자는 그대로 둠 / 번역 |
| 같은 그림·시리즈 | 묶음 기준본을 먼저 확정하고 나머지를 맞춤 |
| 보고 | 비교 시트(원본 | 지운 뒤 | 한글) + 변경 픽셀 수 |
```

## §5 회귀·위험 점검표

행은 게임의 교체 단위(파일·아카이브·빌드 옵션)대로 만든다. 분야 목록에 없는 행은 만들지 않는다.

```
| 교체 단위 | 바뀐 파일 수 | 크기 변화 | 압축(원본/새) | 체크섬·서명 | 위험 | 따로 빼서 시험 가능? |
|---|---|---|---|---|---|---|
| (예: 대사 아카이브) | | | | | | |
| (예: 폰트) | | | | | | |
```
